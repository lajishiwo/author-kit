# 架构图多视角输入候选

三组均来自 SPAR-7M-RGBD / ScanNet++，每组同一场景、同一可辨认主体、三张真实原始帧。RGB 文件逐字节复制，无裁剪、无标记、无颜色修改；拼图仅缩放用于预览。它们是人工挑选的展示组合，不宣称对应数据集某一官方 QA 三视图组合。

- **A_round_table**：黑色圆桌与蓝色高脚椅，背景相对简单，主体关系直观。
- **B_meeting_table**：会议桌，桌椅及桌上电话帮助辨认不同视角，优先推荐。
- **C_yellow_bed**：黄色床铺，颜色醒目，适合小尺寸输入缩略图。

查看 `ALL_CANDIDATES.jpg` 比较；每个子目录含三张原始 RGB、各自的相机 pose 文本和一张横向预览。`manifest.json` 记录场景、帧号、原始路径、对应深度路径、内参目录、尺寸与校验哈希。

本次仅提供选图素材，尚未替换论文中的架构图，也未提交或推送仓库。
