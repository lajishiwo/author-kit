\begin{abstract}
Can measured geometry improve continuous spatial reasoning in vision-language models? We study this question with PIGeR, which integrates relative camera poses and frozen BIP3D RGB-D features into 3DThinker. An adaptation of the CGMF module from SpaceMind updates existing visual tokens before language processing. A zero-initialized residual scale preserves the original visual prefix at initialization. The model retains eight recurrent continuous latents, with no additional language input tokens or direct geometry-to-latent attention. We compare camera-guided fusion with GENERIC, a control with the same inputs and trainable parameter count, and B0, the RGB-only backbone. At 30,000 optimizer steps, single-seed SPAR-Bench Full macro scores are 48.530 for CGMF, 50.345 for GENERIC, and 49.489 for B0. CGMF trails GENERIC by 1.814 points, with a paired 95\% bootstrap interval of $[-2.577,-1.043]$. Development-set pose and geometry substitutions reduce the aggregate score, but their Overall intervals include zero. These results do not support an overall benefit from camera-specific conditioning in this configuration. The matched comparison separates the fusion design from input availability, while the task analysis shows effects obscured by the aggregate score.
\end{abstract}
