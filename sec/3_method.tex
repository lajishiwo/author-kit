\section{Method}
\label{sec:method}
\subsection{Inputs and Fusion Interface}
For a sample with $S$ views, the inputs comprise RGB images $I_i$, measured depth $D_i$, intrinsics $K_i$, camera-to-world transforms $T_{w\leftarrow i}$, and a question $q$. The frozen Qwen visual encoder and merger produce $V_i\in\mathbb{R}^{n_i\times2048}$. A geometric branch produces $G_i\in\mathbb{R}^{16\times2048}$ and one camera embedding $P_i\in\mathbb{R}^{2048}$ per view. Fusion returns $V'_i$ of exactly the same shape as $V_i$.

The language model consumes the original question and the enhanced visual prefix. Camera and geometry embeddings are not appended to its input sequence. The fusion module has no question input, and there is no direct geometry-to-latent cross-attention. Figure~\ref{fig:architecture} specifies the interface; the supplied architecture artwork is not present in the current repository.

\subsection{Relative Pose and Coordinate Conventions}
We anchor the pose branch to the first view and compute
\begin{equation}
T_{i\leftarrow0}=T_{w\leftarrow i}^{-1}T_{w\leftarrow0}.
\label{eq:pose}
\end{equation}
This transform maps reference-camera coordinates to camera $i$. With rotation $R_{i\leftarrow0}$ and translation $t_{i\leftarrow0}$, we form
\begin{equation}
p_i=[\operatorname{R6D}(R_{i\leftarrow0});t_{i\leftarrow0}],\quad
P_i=W_p p_i+b_p,
\end{equation}
where $p_i\in\mathbb{R}^9$, translation is in meters, and $W_p$ maps 9 to 2048 dimensions. R6D uses the first two rotation columns~\cite{rotation}. The first view has an identity rotation and zero translation. The translation in Eq.~\ref{eq:pose} is not the camera's displacement expressed in world coordinates.

The BIP3D branch instead uses $T_{0\leftarrow i}=T_{w\leftarrow0}^{-1}T_{w\leftarrow i}$ to express views in reference-camera coordinates. These two transforms are inverses with different roles. Their directions must be preserved in both caching and pose interventions.

\subsection{Frozen Local RGB-D Representation}
Depth is registered to the color-camera grid before feature extraction. The frozen BIP3D Tiny Det extractor~\cite{bip3d} receives RGB, measured depth, intrinsics, and reference-normalized extrinsics, producing multiscale 256-dimensional features. The implementation samples 48 local features per scene using a fixed image grid with nearby valid-depth alignment: 48 for one view, 24 per view for two views, and 16 per view for three views. Bilinear sampling across feature scales is followed by averaging.

Before fusion, 16 features are selected deterministically for each view and projected by a trainable linear map from 256 to 2048 dimensions. The resulting tokens contain BIP3D feature values; raw XYZ coordinates, raw depth, object boxes, and target relation labels are not concatenated to them. Sampling does not use question-conditioned object regions. These choices keep the interface compact, but can discard details relevant to the question.

\subsection{Adapted Camera-Guided Fusion}
We adapt SpaceMind's CGMF~\cite{spacemind} with visual, pose, and geometry widths of 2048 and an internal attention width of $d=256$. The following equations describe the computational roles; learned linear maps include their implementation biases.

\paragraph{Camera-conditioned keys and values.}
Let $\bar V_i=\operatorname{LN}(V_i)$ and $\bar G_i=\operatorname{LN}(G_i)$. Initial projections are
\begin{equation}
Q_i=\bar V_iW_Q,\quad K_i^g=\bar G_iW_K,\quad U_i^g=\bar G_iW_U.
\end{equation}
Project the current camera as $c_i=W_cP_i+b_c$. Broadcasting $c_i$ over the 16 tokens gives the feature bias
\begin{equation}
B_i=\operatorname{MLP}([\bar G_i;\operatorname{repeat}_{16}(c_i)]).
\end{equation}
It is added to both $K_i^g$ and $U_i^g$. This is an additive feature bias, not a three-dimensional distance term added to attention logits.

\paragraph{Geometry importance.}
A geometry-only self-attention block produces context $C_i$. A learned residual projection and LayerScale combine it with $\bar G_i$ to predict sigmoid weights:
\begin{equation}
w_i=\sigma\!\left(\operatorname{MLP}_w(W_r\bar G_i+\operatorname{LS}(C_i))\right).
\end{equation}
The weighted values are $\widetilde U_i^g=w_i\odot(U_i^g+B_i)$ and keys are $\widetilde K_i^g=K_i^g+B_i$. The importance weights have no separate depth-confidence supervision.

\paragraph{Local geometry and all-view cameras.}
For view $i$, define camera memory rows $M^c_{i,j}=c_j+e_j+\mathbf{1}[i=j]e_{\rm cur}$, with sinusoidal view-order encoding $e_j$ and a learned current-view marker. Cross-attention uses
\begin{align}
K_i^*&=[M_i^c;\widetilde K_i^g],\quad U_i^*=[M_i^c;\widetilde U_i^g],\\
H_i&=\operatorname{LN}\!\left(W_o\operatorname{Attn}(Q_i,K_i^*,U_i^*)\right).
\end{align}
Thus each view attends to its own 16 geometry tokens and all $S$ camera tokens. Other views' geometry tokens are not directly included in this attention memory. Cross-view reasoning can still occur later in the shared language context.

\paragraph{Gating and residual integration.}
Camera-conditioned SwiGLU produces an update proportional to $W_hH_i\odot\operatorname{SiLU}(W_gc_i+b_g)$. Let $F_{\rm CGMF}$ denote the complete reused block, including its internal visual residual and dropout. The outer integration is
\begin{equation}
V'_i=V_i+\alpha\big(F_{\rm CGMF}(V_i,P,G)-V_i\big),\quad\alpha_0=0.
\label{eq:residual}
\end{equation}
The initial fused visual prefix equals the backbone prefix. This equality concerns fusion initialization, not the behavior of the model after optimization. No pretrained SpaceMind fusion weights are loaded.

\subsection{Continuous Latents and Training}
The original recurrent computation uses the preceding final hidden state as the next latent input embedding, iterating eight times. In schematic notation,
\begin{equation}
Z=F_{\rm latent}(V',q),\qquad Z=(z_1,\ldots,z_8),
\end{equation}
followed by autoregressive answer decoding conditioned on $V'$, $q$, and $Z$. Latents have no assigned camera, scene, or relation roles. Geometry's influence is mediated by $V'$; this architecture alone does not show what geometric computations occur within $Z$.

Training starts from the original pretrained 3DThinker-Mindcube checkpoint, not B0 at step 25K. The Qwen visual encoder and merger, base language model, and BIP3D extractor are frozen. Trainable components are language LoRA, pose and geometry projections, CGMF, and residual scaling. There are 29,933,568 LoRA parameters and 10,677,890 fusion-branch parameters, totaling 40,611,458.

For supervised assistant positions $\mathcal A$, the objective remains
\begin{equation}
\mathcal L=-\sum_{t\in\mathcal A}\log p_\theta(y_t\mid y_{<t},V',q).
\end{equation}
It includes the backbone's latent/format-token and answer supervision; user input positions are masked. No geometric regression, distillation, contrastive objective, or reinforcement learning term is added.

\subsection{Matched GENERIC Control}
GENERIC retains all inputs, projections, token counts, parameters, and initialization. It changes two conditioning sources: the K/V bias MLP uses the geometry token and its key representation instead of the current camera projection, and the output gate uses the mean visual query instead of the current camera projection. All-view camera tokens remain ordinary attention memory. Comparing CGMF with GENERIC isolates these two camera-specific conditioning choices jointly; it does not isolate the effect of having pose information at all.
