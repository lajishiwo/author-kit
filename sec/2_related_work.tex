\section{Related Work}
\label{sec:related}
\paragraph{Continuous spatial reasoning.}
3DThinker investigates geometric imagination for spatial reasoning from limited views~\cite{thinker}. We retain its pretrained backbone and use eight recurrent continuous latents in the present configuration. PIGeR changes the visual evidence available to this computation. Answer generation can also attend directly to the visual prefix, so a benefit from geometric inputs would not by itself identify an effect mediated by the latent states.

\paragraph{Camera-guided multimodal fusion.}
SpaceMind introduces CGMF to guide fusion between visual and spatial features using camera representations~\cite{spacemind}. PIGeR reuses its camera-conditioned K/V feature bias, geometry importance weighting, and output gating. The adaptation connects measured relative poses and frozen BIP3D features to the post-merger visual interface of 3DThinker. No pretrained SpaceMind CGMF weights are loaded. The contribution evaluated here is the adaptation of camera-specific conditioning to this interface. GENERIC controls for inputs and trainable parameter count.

\paragraph{Explicit RGB-D features.}
BIP3D connects image representations with 3D perception for embodied intelligence~\cite{bip3d}. We reuse the frozen feature extraction components of its Tiny Det checkpoint, including RGB and depth feature extraction and spatial enhancement. These features combine appearance, depth, and position information. They provide feature-level geometric input without outputting object detections or an explicit scene mesh. Relative rotation is encoded using the first two columns of a rotation matrix, following the continuous 6D representation studied by Zhou \etal~\cite{rotation}. This pose encoding does not impose equivariance on the learned fusion module.

\paragraph{Adaptation and evaluation.}
LoRA learns low-rank parameter updates while keeping the underlying weights frozen~\cite{lora}. We apply it to the language decoder and jointly train the added fusion components. SPAR provides spatial perception and reasoning tasks with RGB-D observations and camera metadata~\cite{spar}. Our experiments use the 20-category configuration and its task macro average. Task-specific scores include numerical partial credit and should not all be read as binary accuracy. Comparisons with RGB-only B0 explicitly account for the measured depth and calibration supplied to PIGeR and GENERIC.
